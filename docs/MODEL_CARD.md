# 모델 카드

## 임베딩 모델

- 모델: `dragonkue/snowflake-arctic-embed-l-v2.0-ko`
- revision: `55ec6e9`
- 용도: 한국어 정책 발언의 검색·유사도 계산·군집화
- 차원: 1,024
- 최대 토큰 길이: 2,048
- 저장 형식: float16
- 검색 방식: L2 정규화 후 내적
- 보안: 모델 파일만 내려받고 회의록은 로컬에서 처리

### 선택 이유

- 한국어 문장 검색에 맞춰진 임베딩 모델
- 문서와 검색어 임베딩을 분리하는 query prompt 지원
- RTX 4060 Laptop GPU에서 전체 처리가 가능한 크기
- 1,024차원으로 검색 정밀도와 저장 용량의 균형이 적절

### 한계

- 의회 특유의 긴 발언·법령 인용·복합 안건이 한 벡터에 섞일 수 있다.
- 유사한 행정 표현이 정책 의미보다 강하게 반영될 수 있다.
- 이를 정책 후보 필터, 의미 자식 청킹, 군집 품질 게이트로 완화한다.

## 로컬 LLM

- 실행기: Ollama
- 모델: `qwen3:8b`
- 용도: 군집 대표 발언의 이슈명·요약·정책 분야 제안
- 설정: temperature 0.1, JSON 구조 출력
- 데이터 전송: localhost만 사용

### 선택 이유

- 한국어 정책 문장을 이해할 수 있는 범용 성능
- 노트북·데스크톱에서 로컬 실행 가능한 크기
- 구조화 JSON 출력과 근거 번호 지정을 구현하기 쉬움

### 안전장치

- 대표 발언마다 독립 주제를 먼저 작성
- 지지 근거와 이상치 근거 번호를 분리
- 동일 이슈 지지율 75% 미만은 `mixed`
- 2개 이상 의회가 지지해야 교차 의회 분석 후보로 인정
- 최종 `issue_id`는 사람 검수 후 고정

## 군집화

- 알고리즘: MiniBatchKMeans
- 선택 군집 수: K=160
- K=100 대비 중심 유사도와 군집 크기 분포를 개선
- 군집 대표 발언은 중심 벡터와 가까운 청크를 사용

KMeans는 모든 청크를 반드시 하나의 군집에 배정하므로 군집이 존재한다는 사실만으로
정책 이슈가 확정되지는 않는다. LLM 품질 판정과 사람 검수가 필수다.

## 예측 모델

### 기준 모델

로지스틱 회귀는 변수의 증가·감소와 예측 확률의 관계를 비교적 설명하기 쉬워 기준
모델로 사용한다.

### 비교 모델

LightGBM은 모멘텀·기울기·확산률 사이의 비선형 관계를 학습할 수 있다. 단, 표본이
작으면 과적합될 수 있어 반드시 시간순 검증을 적용한다.

### 채택 기준

- 마지막 4개월 시간순 검증
- F1 ≥ 0.25
- balanced accuracy ≥ 0.55
- 둘 중 하나라도 미달하면 모델을 사용하지 않고 `trend_fallback`

실제 제출본에서는 목표별 검증 성능과 채택·거부 사유를 `model_comparison.json`에
기록한다. 모델 하나라도 규칙 기반으로 대체되면 결과 신뢰도를 보수적으로 표시한다.

## 금지·제한 사항

- 회의록을 OpenAI·Anthropic 등 외부 상용 LLM API로 전송하지 않는다.
- 제공 기간 이후 외부 정보를 예측 입력으로 사용하지 않는다.
- 이슈 후속 관측 순서를 실제 정책 인과관계로 표현하지 않는다.
- 낮은 신뢰도 결과를 확정적인 정책 예측으로 제시하지 않는다.
