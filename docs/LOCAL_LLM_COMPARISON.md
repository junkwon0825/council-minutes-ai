# 한국산 로컬 LLM 비교 (main.py `/api/chat` 답변 생성 단계)

- 일시: 2026-11-02 · GPU: RTX 4060 Laptop 8GB · Ollama 기본 옵션(services.py와 동일 요청 본문)
- 입력: 질문 8개(대표 이슈 7 + 존재하지 않는 "화성 이주민 조례" 미끼 1) × 검색 근거 6건. 모든 모델에 같은 근거(`evidence_top6.json`)
- 근거 검색은 dense(HNSW)만 사용: `search()`의 전문검색 절은 tsvector GIN 인덱스가 없어 90만 행을 순차 스캔(질문당 수 분)
- 재현: `python scripts/compare_korean_llms.py --models <모델...>` → `python scripts/summarize_llm_compare.py`
